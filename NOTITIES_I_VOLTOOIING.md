# NOTITIES_I_VOLTOOIING (Vadsrijk fix round 2, agent I-VOLTOOIING, branch 110-i-voltooiing)

The zone completion tracker: the **Verkenningsboek** (key **B**, Vadsrijk category).
Package `feature/vadsrijk/voltooiing` (new; registry `VoltooiingRegistry`, client `client/VoltooiingClient`), generator
`tools/features/vadsrijk_voltooiing.py` (texts only; appended to `tools/features/__init__.py` FEATURES).

## What it does
- **Per zone a page** (zone 1 "De Knuffelzwammen", zone 2 "De Splinterpieken") with categories, x/y each, an overall %:
  | category | source (nothing duplicated, read live) |
  |---|---|
  | Hoofdverhaal | quests `soort hoofd` of that zone (`Questlog.status`; busy = yellow, not counted) |
  | Zijmissies | quests `soort zij` of that zone (class advancement quests are NOT counted: per class, optional) |
  | Uitkijkpunten | `WereldPlekken.UITKIJKEN` / `Z2WereldPlekken.UITKIJKEN`, seen = kern `gezien "vr_w_uitkijk_<id>"` |
  | Kampvuren | `WereldPlekken.KAMPVUREN` / `Z2WereldPlekken.KAMPVUREN`; NEW per-player memory via `Haken.KAMPVUUR` (snapped to the known campfire within 3 blocks), or the checkpoint at it (old saves) |
  | Geheimen | Mika clues + treasures/hidden rooms (`extra("npc").aanwijzingen/schatten`, zone 2 `z2_aanwijzingen/z2_schatten`) |
  | Verloren knuffels | `extra("npc").knuffels` / `z2_knuffels` |
  | Bazen | kern first-kill key `baaskill:<type>` OR the quest that ends the fight (Mika-spion = `geheim_spion`, Boormeester = `z2_geheim_boormeester`, Spiegelzucht also via `spiegelbeeld`) |
  | Huisdieren | `Huisdieren.alle()` whose boss id is `vr_z<N>_...` (else zone 1) |
  | Rijdieren | zone 1: Hoedhupper, Klodderros, Knuffelhert; zone 2: Guhwolf (`Rijdieren.heeft`) |
  | Gebieden | NEW memory via `Haken.GEBIED_BETREDEN`; for old saves an area also counts when anything there is done (campfire, lookout, secret) |
- Zone of a quest: id prefix `z2_`..`z9_` (single digit: zone 1's own side quests are `z01_..z20_`), else zone 1.
- Entries: done = green tick + name; busy = yellow; not done = grey name, secrets (`geheim`) "???" + a hint
  ("Ergens in het Sporenwoud...", "Vraag eens rond bij Oma Truus.", "Volg het verhaal..."). Hover = tooltip with the hint.
- **Rewards**: checked every 5 s per player in the dimension (spread, never during a scene) and when the book opens.
  25/50/75 % = a pink toast (KnusToast) + chime + chat line; only the highest new step (old saves don't get 3 toasts).
  100 % = title card "Helemaal verkend!" + title `vr_kenner_van_zwamzoet` / `vr_kenner_van_de_splinterpieken` (titles feature,
  purple) + Vadsmunten (zone 1: 50 zilver, zone 2: 2 goud 50 zilver), once.
- Storage `SpelerData.extra("voltooiing")`: `gebieden`, `vuren`, `mijlpaal`, `beloond`.
- **Screen** `BoekScherm` (extends EcoScherm, 380x232): an open pink book; zone bookmarks in the title band; left page: big %,
  "x van de y gedaan", ribbon bar, the 100 % reward line, the category rows (icon, x/y, mini bar; click); right page: the entries
  (scroll wheel). Its tab "Verkenningsboek" (order 30) sits next to Rijdieren/Huisdieren in i-ui's `CollectieTabs`
  (branch 110-i-ui merged in; BoekScherm overrides `collectieTab()`).
- **Key B**: no vanilla conflict; the snuffel "blaf" (Guhs category) is also B: in the dimension the book wins (same swallow trick
  as the pet key). Pressing B again in the book closes it.
- Dev: `/guhs vadsrijk boek scherm | tel | check | reset`.

## Adding zone 3
`Voltooiing.registreer(new ZoneBoek("zone3", "vadsrijk.voltooiing.zone.zone3", "vr_kenner_van_<x>", <brons>, () -> List.of(...)))`
from the zone-3 registry class, building categories with the public helpers in `ZoneBoeken` (`quests(3, Quest.Soort.HOOFD)`,
`uitkijken`, `kampvuren`, `geheimen`, `baas`, `huisdieren(3)`, `rijdieren`, `gebieden`). Texts: the zone name + the title
(`gui.guhs.titels.naam|hint.<id>`). The title registers itself.

## Open choices
- Vahoegnir is a non-combat flyover: not a boss entry (its zone-2 quest "z2_hq09_draak" is in the main story).
- Elites (optional in the brief): not tracked (no per-elite identity exists); could be a "n elites opgevrolijkt" counter later.
- Class advancement quests not counted (per class; would make 100 % require all 3 classes).
- Pluimguh / Wolkenschaapje / Slakkie (stal/zone 3) are in no zone page.
- Percentages are per entry (campfires weigh as much as quests); 100 % is the same either way.
