# Guhs 1.10 "Het Vadsrijk" - Dutch -> English name glossary

This table is **binding** for every Vadsrijk translation (en_us). It adds to the 1.2.0 glossary
(`tools/lang/GLOSSARY.md`), which stays binding for everything it already covers. Use these exact English forms in
every key: item names, dialogue, quest text, signs, books. The machine-readable copy is `glossary_vr.json`.

## Naming conventions used

- **Vads = Chonk.** Het Vadsrijk = *The Chonkdom*, Vads (the bar) = *Chonk*, Vadsmunt = *Chonk Coin*,
  Hoogvads = *Highchonk*, Vadsvoet = *Chonkfoot*. **Knuffel- = Snuggle-** in names (Knuffelkamp = *Camp Snuggle*,
  Knuffeltij = *Snuggletide*), *Plushie* for toys. **Pluis = Fluff**, **Zwam = Shroom** (Opperzwam = *Overshroom*),
  **Klodder = Blob**, **Galm = Echo**, **Schemer = Dusk**, **Grauw(e) = Gray** (the color of the Chonklessness),
  **Kandij = Candy**, **Kruin = Canopy**, **Wolkwacht = Cloudwatch**.
- **Opper-** = *Over-* (Opperzwam = *Overshroom*, Opperpluis = *Overfluff*), as in the 1.2.0 glossary.
- **Places** get short, pronounceable English place names, punny where possible (Zwamzoet = *Shroomsbury*,
  Kandijkom = *Sugarbowl*, Schorsstad = *Barkton*, Honingtak = *Honeybough*). Dutch articles: drop "the" where English
  would (De Schorsstad = *Barkton*, Het Knuffeltij-strand = *Snuggletide Beach*), keep it where English keeps it
  (De Splinterpieken = *the Splinter Peaks*). Mid-sentence "the" is lowercase.
- **NPCs: title + name, both translated.** Titles: Kok = *Cook*, Bakker = *Baker*, Smid = *Smith*, Oma/Opa =
  *Granny/Grandpa*, Juf = *Miss*, Ridder (as a title) = *Sir*, Kapitein = *Captain*, Havenmeester = *Harbormaster*,
  Stalmeester = *Stable Master*, Ordemeester = *Order Master*, Leermeester = *Mentor*, Wapenhandelaar = *Weapon Trader*,
  Koopman/Koopvrouw = *Trader*, Klerk = *Clerk*, Imker = *Beekeeper*, Uitgevadste = *Unchonked*. Job-guh titles
  join into one word: Brouwguh = *Brewguh*, Smidguh = *Smithguh*, Naaiguh = *Stitchguh*, Winkelguh = *Shopguh*,
  Marktguh = *Marketguh*, Postguh = *Postguh*. Guard ranks: Kristalwacht = *Crystal Guard*, Honingwacht =
  *Honey Guard*, Kustwacht = *Coast Guard*, Wolkwacht = *Cloudwatch*, Kloofwacht = *Gorge Guard*.
  The bare name alone uses the same English (Knapperkorst = *Crispycrust*).
- **Cheese villains keep their cheese** (Baron Bleu, Kapitein Roquefort, Opzichter Gorgonzola, Takelmeester Taleggio).
- **The Emperor's ranks** are hand parts (he "has long arms"): de Keizer = *the Emperor*, de Vingers = *the Fingers*
  (generals), de Ringvinger = *the Ring Finger* (Duchess Ringaling), Knokkel = *Knuckle*, Kootje = *Pinkie*
  (Kootje Zilverstaart = *Pinkie Silvertail*, "Kootje hoort hiervan!" = "Pinkie will hear about this!").
- **Akim stays Akim**: it is Mika spelled backwards (the joke must keep working).
- Kept as-is on purpose: Mika, guh, Guhdex, Guhmension, Siq, Baron Bleu, Tip & Tap, Smash, Confetti, Mo, Kiki,
  Tilly, Bea, Nectar(ine), Dinar, Guhwolf, Splinterling, the cheese names.
- American spelling (Gray, Armor, Harbor, Color). Item names in Title Case.
