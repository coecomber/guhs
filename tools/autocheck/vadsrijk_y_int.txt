# Y-INT: round Y, the REAL survival <-> Vadsrijk border (the gametest server has no Vadsrijk dimension, so this is where it is
# checked for real). /guhs grenscheck (feature/vadsrijk/scheiding/GrensCheck) does the checks server-side and writes
# "GRENSCHECK PASS|FAIL|SKIP ..." lines to the log, to chat and to run/grenscheck.txt; the shots are only the evidence.
# Run it with openZones = 1 in run/defaultconfigs (the release gate), FTB Essentials in run/mods:
#   gradlew runAutocheckClient -PautocheckScript=tools/autocheck/vadsrijk_y_int.txt
