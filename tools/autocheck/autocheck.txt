# Guhs AutoCheck script (dev only) - run with:  gradlew runAutocheckClient   (or run-autocheck.bat)
# Output: run/screenshots/autocheck/*.png + report.txt. The world 'guhs_autocheck' is created fresh every round.
#
# Commands:
#   /<command>                     server command as the player (op), failures go to the report
#   wait <ticks>                   wait
#   waitrender [maxTicks]          wait until the chunks around the camera are loaded and built
#   look <yaw> <pitch>             hold the camera rotation;  unlock  frees it again
#   camera <x> <y> <z> <yaw> <pitch>  teleport in the current dimension and hold the rotation
#   shot <name> [gui]              screenshot to screenshots/autocheck/<name>.png (HUD hidden unless 'gui')
#   gui guhdex [prefix] [none]     open the Guhdex (all seen, or nothing seen) and shoot every page
#   gui highscores [prefix]        open the Guhdex's Highscores tab and shoot every page
#   gui knus [prefix]              open the Guhdex's Knus tab and shoot the overview
#   gui creative <namespace|tab>   open the creative inventory at the tab(s) and shoot every page
#   gui ftbquests [prefix]         open the FTB quest book on every Guhs chapter (overview, top to bottom, the Hoe kom je hier? quest)
#   gui close
#   opnieuw                        (3.0) forget what was OK this round (tplocate a structure again, e.g. for camtpl)
#   gui keep                       (3.0) keep the next screen a server command opens, until gui close
#   tplocate <dim|auto> <structure|all>   locate (like /locate) + shoot the structure from 2-4 viewpoints
#   tpbiome <dim|auto> <biome|all>        find the biome + shoot a landscape
#   lineup <variants|npcs|entities|bosses> <x> <y> <z>   platform + creatures in rows, front/back/side shots
#   blockwall <x> <y> <z>          every guhs block on a wall with labels
#   modelcheck                     every guhs block state + item: missing model or missing-texture faces
#   mist on|off                    off = override the biome mists (Vadswoud/Kaasmoeras) for clear far views
#   use <x> <y> <z>                right-click a block (as the player, no item)
#   section <title> / log <text>   headings / notes in the report
#   quit
# (2.9 visual QA commands)
#   interact <x> <y> <z> [type]    right-click the nearest entity (opens its screen; needs creative/survival)
#   wardrobe|guhmenu|piepmenu <x> <y> <z>   tame the nearest guh / piep-maatje and open its wardrobe / menu
#   ontgrendel all|<id>...         unlock clothing pieces for the player
#   mouse|click <gx> <gy>, drag <x1> <y1> <x2> <y2>, scroll <gx> <gy> <n>, type <text>, press <label>   drive the open screen
#   widgets                        list the open screen's widgets; flags overlaps, off-screen widgets and too-long button texts
#   useitem <ticks>                hold right-click with the held item
#   emote <x> <y> <z> <r> <EMOTE>  guhs in that radius start an emote (SLAPEN = sleeping eyes)
#   npc <kind> [dist] [dy]         go to the nearest loaded guh_npc of that kind, facing it;  interact npc   clicks it
#   camrel|lookrel|relcmd          camera / commands relative to the last tplocate'd structure's min corner
#   camtpl|looktpl (3.0)           the same, relative to the start piece (= template coords, also with terrain adaptation)
#   gui dexopen <tab> [open]       open the Guhdex on a tab and leave it open
# (2.10 visual QA commands)
#   gui mijnguhs [list|<n>]        the Guhdex tab Mijn guhs with example guhs (list, or the page of guh n)
#   huisje <x> <y> <z>             a groot Guhhuisje (door south) with three residents, its screen open, the dome on
#   samenspel <goed|mis|record> <spel>   your own guhs close by cheer / are sad / dance as after that minigame
#   kart <x> <y> <z> <yaw>         a race guh, the player steering, the nearest own guh on the second seat;  kartinfo
#   racekart <x> <y> <z> <yaw> <niveau> [nosprong]   (2.10.1) a race guh as in a Regenboogbaan race (rainbow jump on), the player steering
#   drive on|off                   (2.10.1) hold W;  kartpos [label]   note where the player's vehicle is (the rider's game)
#   guhkamer stuur [n]|maag|binnen send own guhs to the Guhkamer / go to your Guhmaag / into your Guhkamer
#   doolhofstart <niveau>          start a doolhof game at the nearest doolhofguh
#   speelaltijd <x> <y> <z> <r>    tamed guhs there look for a toy right away
#   neartag <tag> <dist> <dy>      camera dist south / dy above the nearest entity with that tag, looking at it
#   renderdistance <n>, clearchat  view distance (overviews) / empty chat before a HUD shot
