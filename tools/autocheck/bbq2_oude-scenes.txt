# bbq2 verhalenpad, oude-scenes (AutoCheck, dev only): the six camera scenes of the older stories. Run:
#   gradlew runAutocheckClient -PautocheckScript=tools/autocheck/bbq2_oude-scenes.txt
# (commands: see autocheck.txt; the op commands used here: /guhs oudescenes stand | speel <scene> | vergeet <scene> | ga <scene>,
#  feature/oudescenes/OudeScenesFeature.java)
# For each scene the script puts the story's own template down unrotated (/place template: there is no structure start, so the
# scene anchors on the block the player stands on, which is the template's anchor block) and plays the scene with
# /guhs oudescenes speel. Shots at the beats of each script (tools/features/oude_scenes_scene.py).
# NOT run by the slice itself (no game client in phase 2): this is for the visual check. What only a client shows and nobody
# has seen yet: every camera, the cast in place, the white fog and the snow of the Balto scene, the rain, thunder, night and
# lightning of the Mewtwo scene, the night and the picture book (an item display, laid flat) of the ohana scene, the beam and
# the heart that starts to beat, the portal that is dark until the flame has run round, the front door that opens.
# World anchors: template corner + the scene's anchor (Scenes.<KORT>_ANKER).
