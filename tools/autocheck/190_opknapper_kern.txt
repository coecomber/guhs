# 1.9 "Een opknapper!", kern slice: the village economy and the overview UI (AutoCheck, dev only). Run:
#   gradlew runAutocheckClient -PautocheckScript=tools/autocheck/190_opknapper_kern.txt
# 1280x720 at gui scale 2 = 640x360 gui pixels. The overview is steered with the dev command /guhs erfenis ui

# windows: Opslag, Naar huis, Loket, Bouwkeet blocks, Guhpension.
