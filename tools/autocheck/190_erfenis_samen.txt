# 1.9 POC, De Erfenis: core + wereldkaart together (AutoCheck, dev only). Run:
#   gradlew runAutocheckClient -PautocheckScript=tools/autocheck/190_erfenis_samen.txt
# 1280x720 at gui scale 2 = 640x360 gui pixels. Overview top-left buttons (y 40..54): Sluiten | Terug naar de wereld |
# Wereldkaart (x ~182..254) | for a visitor: Terug naar mijn erfenis (x ~258..393).
# Flow: own overview (no HUD/minimap, Bouwspul clamped), Wereldkaart button, an NPC village from the Ranglijst -> Bezoeken,
# then its Bovenaanzicht (read only), Terug naar mijn erfenis, and the map's Terug button back to the overview.
